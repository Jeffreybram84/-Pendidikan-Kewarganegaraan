# Ujian Pendidikan Kewarganegaraan UT — Jeffrey Bram

Aplikasi Android offline berbasis WebView untuk latihan/ujian Pendidikan Kewarganegaraan UT.

**Pembuat:** Jeffrey Bram

## Fitur
- Modul dan tes formatif
- Timer ujian
- Pengacakan soal
- Penilaian otomatis 0–100
- Review jawaban dan kunci
- Responsif untuk HP/tablet
- Offline
- Logo MJ sebagai ikon aplikasi

## Build APK dari GitHub
Workflow GitHub Actions akan membangun APK debug setiap push ke `main`, atau dapat dijalankan manual melalui **Actions → Build Android APK → Run workflow**.

APK tersedia pada **Artifacts** setelah workflow selesai.
